Sibin & Sneha Wedding Website

Extract the ZIP, then open index.html in your browser.
Edit index.html for text, location and phone numbers.
Edit style.css for layout, fonts and colours.
Keep assets/invitation.png in its folder; it supplies the artwork.
reception.ics is the calendar download.

No installation or build step is required. Upload the folder contents to any static web host.
An internet connection loads the Google Fonts; fallback fonts work offline.
